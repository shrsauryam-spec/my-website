# My First HTML/Tailwind Website
In this project, I built my first-ever website using **HTML** and **Tailwind CSS**. I gave a short introduction of myself on the website with an image of something that fascinates me. I added some more features to the website. The features being a few buttons that highlights my interests and directs users upon click to websites helping them begin on that particular interest.
